# SLVVPN 客户端安装包

Windows 与 macOS 下载官方原始 OpenVPN Connect 安装包；安卓和平板使用开发者官方 GitHub 发布的 OpenVPN for Android。文件未经修改。

| 平台 | 版本 | 下载 |
|---|---|---|
| windows | 3.9.0 | [openvpn-connect-3.9.0.5008_signed.msi](https://github.com/UncleJoker/slvvpn-client-downloads/releases/download/clients-2026-10-11/openvpn-connect-3.9.0.5008_signed.msi) |
| macos | 3.8.2 | [openvpn-connect-3.8.2.6009_signed.dmg](https://github.com/UncleJoker/slvvpn-client-downloads/releases/download/clients-2026-10-11/openvpn-connect-3.8.2.6009_signed.dmg) |
| android | 0.7.65 | [ics-openvpn-0.7.65.apk](https://github.com/schwabe/ics-openvpn/releases/download/v0.7.65/ics-openvpn-0.7.65.apk) |

Windows 使用 MSI，macOS 使用 DMG，Android / Android 平板使用 APK。iPhone / iPad 请通过 [App Store](https://apps.apple.com/app/openvpn-connect/id590379981) 安装。

可用 SHA256SUMS.txt 核对完整性。GitHub 和安装包下载域名在不同网络下可能受限；不能保证中国大陆所有网络无需 VPN 都能下载。
